# Устройство оригинальной игры

Заметки по восстановлению «Перестройки» из `PERESTR.EXE`: где что лежит в
оригинале и как это перенесено. Адреса даны в виде `сегмент:смещение`
относительно загрузочного образа EXE.

## Исполняемый файл

`PERESTR.EXE` (75 172 байта, 11.07.1990) собран Turbo C 2.0 в модели large.

| Сегмент | Содержимое |
|---|---|
| `0000:0000–01C9` | стартовый код `c0` |
| `0000:01C9–0829` | ассемблерные процедуры «спецэффектов»: снятие спрайта с маской, вывод спрайта по маске, копирование прямоугольника между видеостраницами через защёлки EGA |
| `0000:0829–0A00` | музыкальный проигрыватель В. Н. Мурогова (Rev 4.5) |
| `0000:1C5B–4E50` | графическая библиотека BGI (`graphics.lib`) |
| `04E5` | модуль игры, около 21 КБ, 50 функций |
| `0A0F` | загрузчик PCX |
| `0CB2` и далее | рантайм Turbo C, эмулятор 8087, DGROUP (`1042`) |

Графика — режим EGA 640×350×16 с двумя видеостраницами. Драйвер
`EGAVGA.BGI` загружается из файла. Игра рисует на странице 1 и переносит
готовые области на видимую страницу 0.

### Звук

Проигрыватель перепрограммирует канал 0 таймера на 1193182/64 ≈ 18,6 кГц и
выводит 6-битный отсчёт на каждом втором прерывании через одновибратор
канала 2 (ШИМ на PC-спикер). Частота дискретизации получается ≈ 9322 Гц.
Звук проигрывается блокирующе: процессор ждёт в `HLT`, пока звучит фраза.
Остальные звуки получаются через `sound()`/`nosound()`, в том числе свипы
вида `for (f = 50; f < 2000; f++) sound(f);`, длительность которых зависела
от скорости процессора.

## TOPPLER.DAT

Файл читается последовательно, смещения фиксированы:

| Смещение | Размер | Содержимое |
|---|---|---|
| 0 | 158 100 | звуковая заставка (617 страниц по 256 байт) |
| 158 100 | 65 376 | титульная картинка, PCX 640×350, 4 плоскости |
| 223 476 | 4 × 427 | Демократ, 4 направления (вверх, вправо, вниз, влево) |
| 225 184 | 25 × 427 | монеты этапов 1–25 |
| 235 859 | 8 × 607 | Бюрократ, 8 кадров |
| 240 715 | 1 417 | крест |
| 242 132 | 7 427 | надпись «Примите соболезнования» |
| 249 559 | 1 387 | облако |
| 250 946 | 2 470 | звук «товары» |
| 253 416 | 7 192 | звук поимки Бюрократом |
| 260 608 | 4 577 | звук «валюта» |
| 265 185 | 3 560 | звук «налог» |
| 268 745 | 7 701 | «ча-ча-ча» к танцу Бюрократов в конце игры |
| 276 446 | 2 023 | векторный шрифт с кириллицей |
| 278 469 | 130 | таблица рекордов: 10 × (long очки + 9 байт имени CP866) |

**Спрайты.** Заголовок из трёх слов: ширина−1, высота−1, число плоскостей
(5). Затем идут плоскости в порядке 3, 2, 1, 0 и маска прозрачности. Каждая
плоскость — h строк по `((w−1)>>3)+1` байт.

**Векторный шрифт.** Байт N (число символов−1, коды с 0x21), N+1 ширин,
таблица смещений. Смещение глифа вычисляется как `3N + hi·255 + lo + 1`;
множитель 255, а не 256, — особенность оригинала. Штрихи — пары
`(dx, dy)`: бит 7 у `dy` означает «перо опущено», значения `dy` больше 8 —
отрицательные. Символы набраны латиницей по раскладке ЙЦУКЕН: строка
`Dthcbz` выводится как «Версия»; `%` — «:», `&` — «.», `^` — «,».

**Шрифт 8×8** (рекорды, счёт, статистика) рисует драйвер BGI. Буквы
`A`–`z` берутся из собственной таблицы `EGAVGA.BGI` (смещение 0x8E9), цифра
«0» рисуется глифом буквы «O». Остальные символы до 0x80 берутся из ПЗУ
BIOS, начиная с 0x80 — из таблицы по вектору int 1Fh (CP866 на русских ПК).
В порте вместо этих глифов используется свободный шрифт unscii-8
(общественное достояние) в кодировке CP866: `internal/gfx/font8x8.go`.

## Время

В игровом цикле нет задержек: за один «ход» обходятся все листья, и темп
определялся скоростью процессора и видеоадаптера. Основное время уходило на
заливку эллипсов средствами BGI. В порте каждый примитив `internal/gfx`
добавляет стоимость в «инструкциях», откалиброванную по оригиналу, а
`Game.work` переводит её в паузы из расчёта 2,5 млн инструкций в секунду
при скорости 1.0. Так получается примерно 0,3 с на ход на первом этапе
и около 0,65 с на этапах с полем 14×8. Задержки `delay()` оригинала
воспроизводятся в реальном времени.

## Отладочный режим и сверка

`-script файл` запускает игру без окна в виртуальном времени. Строки
сценария имеют вид `<секунды> <команда>`, где команда — одна из:

- `key <клавиша>` — нажатие (`space`, `enter`, `esc`, `up`, …, или символ);
- `shot <файл.png> [страница]` — снимок экрана;
- `tickkey <номер хода> <клавиша>` — нажатие в начале указанного хода;
- `quit` — завершение.

Дополнительные флаги:

- `-debug-rnd N` делает игру детерминированной: F_0FB4 всегда возвращает N;
- `-debug-level N` начинает игру с этапа N;
- `-debug-state файл` пишет полное состояние в начале каждого хода;
- `-wav файл` записывает звук прогона.

Именно этим режимом порт сверялся с оригиналом. Оригинальный EXE
исполнялся в эмуляторе 8086+EGA, в нём `F_0FB4` подменялась на
`mov al, N; retf`, нажатия подавались в начале тех же ходов, а дампы
состояния сравнивались построчно.
